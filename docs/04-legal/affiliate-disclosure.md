# Compensation and Affiliate Disclosure

> Draft wording. chinnzz and, where needed, a qualified reviewer must approve it before launch. This page covers the current no-sponsor state and the wording to use if a deal is signed later.

## Current state: no sponsor, no affiliate deal

The code **CHINNZZ** exists. chinnzz is **not sponsored** and earns nothing from it. The site must say so plainly.

### Short version, inside the code card

> No sponsor and no affiliate deal. I do not earn anything if you use this code. It may simply not work, so check Stake.com before relying on it.

### Footer version

> chinnzz is not currently sponsored and has no affiliate deal. Some links go to third-party sites that set their own terms. If a paid partnership is signed, this page and the code card will say so before you click. 18+ or 21+ depending on where you live. Play responsibly.

### Long version, dedicated disclosure block or page

> chinnzz.com is a personal site for the streamer chinnzz. At the time shown below, chinnzz has no sponsor and no affiliate agreement.
>
> The Stake code shown on this site is provided for information. chinnzz does not receive commission, credit or any other benefit if you use it. It may not be active. Confirm the current terms on Stake.com before you rely on it.
>
> The site links to Kick, X, Discord and Stake.com. Those services have their own terms and privacy policies. chinnzz is not a gambling operator, casino, sportsbook or financial advisor.
>
> If a paid partnership or affiliate agreement is signed in future, the code card and this page will be updated before the link goes live. Sponsored content will always be labelled.
>
> Gambling involves risk. Never gamble money you cannot afford to lose. Only play if you are old enough and it is legal where you live.

Add a visible last updated date. Example: `Last updated: 17 October 2026`.

## State 2: active and sponsored

Use this only after a signed agreement.

### Short version, inside the code card

> Paid partnership. I may earn a commission if you sign up through this code or link. It costs you nothing extra.

### Footer version

> chinnzz has a paid partnership with [PARTNER]. He may earn a commission from signups through this site, at no extra cost to you. 18+ or 21+ depending on where you live. Play responsibly.

### Long version

> chinnzz has a paid partnership with [PARTNER]. If you use the code or link on this site and meet the partner's qualifying conditions, chinnzz may receive a commission. This does not change what you pay.
>
> A commission does not mean the service is right for you. Check the partner's terms, age rules and restricted locations. chinnzz is not the operator and does not handle accounts, deposits, withdrawals or support.
>
> Sponsored posts or videos will be labelled separately.

Use the partner's mandated wording verbatim if it requires one. Record it in the [Content and Assets Checklist](../01-brand/content-assets-checklist.md).

## State 3: code inactive

> No code is live right now. Follow on Kick or join the Discord to hear when one is available.

Do not use the word sponsored when there is no sponsor. Do not leave a sponsored disclosure in place after a deal ends.

## Rules

- The disclosure appears next to the code, not only on a separate page.
- Footer disclosure appears on every page.
- Text is at least 12px and not hidden in a tooltip or collapsed section.
- No color-only or icon-only disclosure.
- Do not call a partner a partner without explaining the financial relationship, if one exists.
- Do not imply endorsement by Kick, Stake or any regulator.
- Update this page the same day a deal starts or ends.
- Keep the current state visible in the admin so the copy cannot drift from reality.

## Placement checklist

- [ ] Code card: state specific disclosure directly below the code.
- [ ] Footer: current disclosure, visible on every page.
- [ ] FAQ: an answer about sponsorship and the code.
- [ ] Privacy policy: reference to third-party links and cookies.
- [ ] Any future sponsored post or video: its own label.
- [ ] Admin: `stake.state` and `stake.disclosure` match the approved wording.

## Legal note

Many jurisdictions, including the US FTC and UK advertising rules, require clear and conspicuous disclosure of material connections. The absence of a connection should not be described as one. This draft is a starting point, not legal advice.
