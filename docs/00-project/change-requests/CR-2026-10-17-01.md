# CR 2026-10-17-01: Scope change for admin, backend and no-sponsor launch

- **Requested by:** chinnzz
- **Date:** 2026-10-17
- **Status:** approved
- **Affects milestone:** M1 to M12

## Request

Change the v1 scope from a static affiliate landing page to a managed single-page hub with an admin panel. The change covers:

1. No sponsor or affiliate deal at launch. chinnzz plays on Stake.com and the code `CHINNZZ` exists but is not sponsored.
2. Monetization moves to Kick subscriptions, tips and donations, and sponsorship inquiries through a public email.
3. Every piece of site content must be editable in an admin panel: copy, links, socials, code state, support links, sponsor details, SEO, media and legal pages.
4. A backend and admin panel will be built now, run locally at first, and deploy to a VPS later. The public site must not depend on that backend at runtime.
5. The public site moves from plain HTML with no build step to Eleventy static output, so content files can be rendered at build time.
6. Design must be mobile-first and must look human made. Four mockup directions are required, including a Hectic-inspired crimson direction.
7. Leaderboard, raffle, deposits and prize mechanics are removed from v1.

## Reason

The original scope assumed affiliate partners and codes that do not exist. It also assumed manual file edits, which does not meet chinnzz's request that all site settings be manageable from one panel. The revised scope keeps the public site fast and independent, while giving chinnzz control of the content.

## Impact

| Area | Impact |
|---|---|
| Scope | Adds admin panel, backend API, content model and build step. Removes leaderboard, raffle, deposits and prize mechanics from v1. |
| Design | Four directions instead of three. Mobile-first is now a hard rule. Human-craft and copy quality checks are added. |
| Development | New Eleventy public build, Express admin, SQLite, auth, media handling and publish flow. |
| Content and assets | Stake link and code status replace affiliate partner placeholders. Sponsor email, tips link, Kick subscription status and admin login are new inputs. |
| Legal and compliance | Disclosure must state that no sponsor exists and the code may earn nothing. Legal pages must cover the admin backend and tips. |
| Timeline | The public site can launch before the VPS phase. Admin deployment becomes a separate milestone after launch. |
| Cost | Cloudflare Pages stays free. A VPS and domain become the only recurring costs. |
