# Monetization and Partnerships

## Current position

chinnzz has no sponsor and no affiliate deal. He plays on Stake.com and the code `CHINNZZ` exists, but it is not sponsored. The site must not imply otherwise.

v1 earns through three honest paths:

1. Kick subscriptions.
2. Tips and donations.
3. Sponsorship inquiries sent to a public email.

Affiliate income is a later phase. The code slot is built now so it can switch on when a real deal exists.

## The code slot

The admin controls one of three states for the Stake.com card:

| State | What the visitor sees | When to use |
|---|---|---|
| `active_sponsored` | The code, a partner link and a disclosure that chinnzz may earn a commission | Only after a written affiliate or sponsorship agreement exists |
| `active_unsponsored` | The code and a clear note that chinnzz is not sponsored and may earn nothing | If chinnzz wants to share the code without a deal |
| `inactive` | "No code live right now" and a follow CTA | Default until the Stake relationship and code terms are confirmed |

Rules:

- Never show `active_sponsored` without a real agreement.
- Never invent a partner, a bonus, a reward or a signup offer.
- The disclosure text is editable in the admin but must match the selected state.
- The code is displayed as selectable text and has a copy button.
- The Stake.com link is a normal outbound link unless a tracked affiliate link exists.
- The site does not claim to operate Stake.com or to be endorsed by it.

## Kick subscriptions

Kick subscriptions are the primary recurring support path once chinnzz is eligible.

- The support section links to the Kick channel.
- The button label states the action: "Subscribe on Kick".
- If subscriptions are not enabled, the section shows tips and Discord instead.
- The site does not promise subscriber perks that do not exist.

## Tips and donations

Use one provider, not several. Ko-fi or StreamElements are the current candidates.

- The button label states the provider action: "Tip on Ko-fi" or "Tip with StreamElements".
- The link opens the provider page in a new tab.
- The privacy policy names the provider.
- No payment details are collected by chinnzz.com.
- No fake progress bars, goals or countdowns.

## Sponsorship inquiries

The site lists a public contact email for sponsors: **business@chinnzz.com**. The mailbox is created once the domain is purchased and mail is set up. Until then the button links to the address and starts working the day the mailbox goes live.

The section answers four questions fast:

1. Who is chinnzz and what does he stream?
2. Who is the audience and how large is it, using real numbers only?
3. What can a sponsor buy: stream mention, overlay, dedicated segment, social post?
4. How does a sponsor start a conversation?

No rate card is published until chinnzz has real audience data and has decided on rates. A simple email CTA is enough for v1.

## Affiliate applications

chinnzz can apply to the Stake affiliate program and other partners in parallel with the build. The site is ready for approval:

- The code slot exists.
- The disclosure exists.
- The admin can switch the state without a deploy.
- Analytics can count code copies and outbound clicks.

Do not apply in the site's name or promise approval. The application is chinnzz's.

## Metrics

| Goal | Metric | Source |
|---|---|---|
| Watch | Watch-live clicks and Kick viewers | Site events and Kick dashboard |
| Community | Discord joins and X follows | Discord insights and site events |
| Support | Kick subscription clicks and tips clicks | Site events and provider dashboards |
| Sponsorship | Sponsor email clicks and inbound messages | Site events and email |
| Code | Code copies and outbound Stake clicks | Site events |
| Reach | Visits and referrers | Cookieless analytics |

Only real numbers go on the site. Audience stats are updated manually in the admin until a reliable source exists.

## What we never do

- Claim a sponsorship that does not exist.
- Invent bonuses, rakeback, free spins or deposit matches.
- Run a raffle or giveaway without a real prize and clear rules.
- Promise winnings or imply that a code improves odds.
- Hide the financial relationship behind vague words such as "partner".
- Target minors or use gambling as a solution to money problems.
